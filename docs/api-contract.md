# ClearPath API contract (v1)

**Status:** local routes and AWS presigned-upload routes are implemented and tested locally. The AWS stack is deployed in account `033890317696`, `us-east-1`, with CloudFormation status `UPDATE_COMPLETE`. Cognito sign-in, bearer-token frontend/API connectivity, CORS preflight handling, and unauthenticated `401` behavior have been live-verified. AgentCore Memory is provisioned, but no runtime strategy ID is configured, so AgentCore ingestion and retrieval are inactive. The complete AWS case upload/analyze/review workflow has not yet been validated. See `docs/handoff.md`.

Python source of truth: `backend/app/schemas/models.py`; OpenAPI at `/openapi.json`.
API base URL defaults to `http://localhost:8000`. JSON errors use `{ "detail": "safe message" }`. All identifiers are UUIDs; identifiers are not authorization.

**Auth:** Local demo mode needs no token, is localhost/synthetic-only and uses one local user. In AWS, API Gateway requires a Cognito access token with the `clearpath/review` scope on every route, sent as `Authorization: Bearer <token>`. The backend reads the verified token's `sub` claim as the user ID and enforces per-user case ownership: case and memory routes return 401 without a user, and other users' cases return 404. The backend itself leaves `/api/config` and `/api/samples*` open (synthetic files only).

- `GET /api/config`: `{mode: "demo"|"aws", banner: string, privacy_notice: string}`.
- `POST /api/cases` JSON `{name: string}` -> 201 CaseResponse.
- `GET /api/cases/{case_id}` -> CaseResponse.
- `POST /api/cases/{case_id}/documents` multipart `file`, `document_type` -> 201 Document (demo only).
- `GET /api/cases/{case_id}/documents/{document_id}` -> inline application/pdf for viewer.
- `POST /api/cases/{case_id}/uploads` JSON `{filename, document_type}` -> PresignedUploadResponse (AWS only). POST multipart to S3 URL with returned fields and file; then `POST /api/cases/{case_id}/documents/{document_id}/complete` -> Document. Keys generated by backend, not accepted from client.
- `POST /api/cases/{case_id}/analyze` -> 202 Job. Returns immediately; processing occurs separately. At most one active run per case; active request returns existing job. Uploads are locked while queued/processing. New analysis invalidates previous run's displayed results but keeps historical review records in storage. Retries of the same run preserve reviews and stable finding IDs.
- `PUT /api/cases/{case_id}/findings/{finding_id}/review` JSON `{status: "accepted"|"dismissed", note?: string, remember?: boolean}` -> ReviewDecision. Findings remain immutable; reviews are separate. `remember: true` approves this decision (pattern and status only, never the note) as review memory; saving again without it withdraws that lesson.
- `GET /api/memory` -> MemorySummary. `POST /api/memory/reset` -> MemorySummary (clears all lessons; demo-mode rehearsals only and returns 403 in AWS mode).
- `GET /api/samples` -> SamplePacket[]. IDs `complete`, `missing`, `conflicting`, `formatting`.
- `GET /api/samples/{sample_id}/{document_type}.pdf` -> downloadable synthetic PDF.
- `POST /api/samples/{sample_id}/load` -> 201 CaseResponse with three uploaded docs (demo only). Frontend then invokes analyze.

CaseResponse fields: `id`, `name`, `created_at`, `documents: Document[]`, `job: Job|null`, `findings: Finding[]`, `reviews: {[finding_id]: ReviewDecision}`, `model_input_preview: object[]`, `checklist: ChecklistItem[]`.
Document: `id`, `case_id`, `document_type` (`client_profile`, `transfer_application`, `account_statement`), `filename`, `size`, `status` (`uploaded` or `pending_upload`). Storage keys never returned.
Job: `id`, `case_id`, `status` (`queued`, `processing`, `completed`, `partial`, `failed`, `interrupted`), `progress` (0–100), `stage`, `errors: string[]`, `created_at`, `updated_at`.
Finding: `id`, `case_id`, `analysis_run_id`, `rule_id`, `policy_version`, `category` (`missing_information`, `identifier_mismatch`, `address_difference`, `review_required`), `severity` (`high`, `medium`, `low`), `origin` (`deterministic_rule` or `model_suggestion`), `explanation`, `recommended_correction`, `evidence: Evidence[]`, `pattern` (privacy-safe kind of finding with no values, e.g. `ADDRESS_REVIEW:formatting_only` vs `ADDRESS_REVIEW:different`), `memory: FindingMemory|null`.
FindingMemory: `pattern_label`, `accepted`, `dismissed`, `total` (approved decisions on this pattern in other cases), `hint` (nullable; set only when past decisions lean clearly), `lessons: string[]` (consolidated by AgentCore Memory when `AGENTCORE_MEMORY_ID` and `AGENTCORE_MEMORY_STRATEGY_ID` are set; shown only while approved decisions for the pattern exist; untrusted text, render as plain text). Advisory only: it never changes, hides or dismisses a finding.
MemorySummary: `enabled`, `patterns: [{pattern, label, accepted, dismissed, total, updated_at}]`, `total_decisions`.
Evidence: `document_id`, `page`, `excerpt` (sanitized), `bounding_box: null|{left,top,width,height}` (normalized coordinates only when real). Local evidence has no bounding boxes. Viewer should open PDF page and show excerpt, never invent highlights.
ReviewDecision: `finding_id`, `status`, `note` (nullable), `remember`, `updated_at`.
ChecklistItem: `finding_id`, `correction`, `reviewer_status` (`pending` or `accepted`); dismissed findings excluded. Accepted means advisor agrees with finding, not that correction is completed.
SamplePacket: `id`, `name`, `description`, `documents: [{document_type, filename, url}]` (relative API paths).

No real LPL policies or regulatory compliance guarantees. Model-input previews contain sanitized comparison outcomes, never source identifiers. When approved review memory exists for a finding's pattern (from other cases, read when the analysis runs), the preview also carries `approved_lessons` (the memory hint plus any AgentCore lessons), and the explanation may cite it as past reviewer experience; the finding itself never changes. Demo explains with deterministic templates. Unsupported extraction must produce partial/failed state and review-required findings, never an all-clear.
